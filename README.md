# Skytracer-Real Time Malaysian Live Flight Monitoring Dashboard

A web-based aircraft monitoring and geospatial visualization dashboard designed to display aircraft activity across Malaysia and surrounding airspace.

## Overview

Skytracer integrates aircraft state data from the OpenSky Network API with an interactive web dashboard, allowing users to explore aircraft positions and flight information on a map.

## Features

- Interactive aircraft tracking map centred on Malaysia
- Aircraft position markers with flight information popups
- Aircraft callsign and country search
- Altitude, speed, heading and ground-status information
- Aircraft count and airborne aircraft statistics
- Automatic and manual data refresh

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **API:** OpenSky Network REST API
- **Mapping:** Leaflet.js, OpenStreetMap
- **Development:** Visual Studio Code, Git

## Getting Started

1. Clone the repository.
2. Install Node.js.
3. Run `npm install`.
4. Start the server using `node server.js`.
5. Visit `http://localhost:3000`.

Live data availability depends on the OpenSky Network API and its authentication and usage limits.
